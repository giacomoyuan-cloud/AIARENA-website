## 账号状态

NativeAccountRegistry 的 Durable Object 墓碑是删号依据。先提交墓碑，再更新 KV；即使 KV 暂时返回旧密码或写入失败，已删除账号也无法认证。KV 更新失败通过 alarm 重试。App 与网页共用权限检查，管理员身份不根据显示名称判断。历史资料保留，删除的是账号访问权限。

## 阅读与稳定性

表格保留全部列；手机逐项模式按字段展示原始内容，桌面表格保持列宽并允许横向滚动。原生界面的滚动按钮移出消息内容，避免遮挡表格。

完整回归发现新字库被解压为十份约 17MB 的缓冲区，触发 192MB Java 堆上限。现在各字重共用一份字库缓冲区，窗口主题不再重复载入 CJK XML 字库；Compose 与 Markdown 继续显式使用原有 Inter / Noto Sans SC。相近阶段 Java heap PSS 从约 200MB 降到约 40–48MB，字形来源校验保持一致。
