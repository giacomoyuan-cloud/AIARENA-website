## 已修复

| 问题 | 原有行为 | 修复和证据 |
| --- | --- | --- |
| P1 无痕内容进入普通历史 | 关闭无痕后继续使用同一个聊天 ID，后续普通保存会把之前的无痕消息写入历史。 | 切换时新建隔离会话；退出前清空私密消息和草稿；缓存区分隐私模式；生成及导航期间禁用切换。合成存储验收中修复前私密标记被保存，修复后未保存。 |
| P1 显示模型与实际请求不一致 | Skills 每次读取共享存储；其他标签页改成文档技能后，当前页面可能仍显示 Sol Low，发送时却切换 Claude。账号别名解析也可能复活旧技能设置。 | 当前页面保留自己的选择快照，发送前核对模型、深度和技能；迁移别名时保留当前选择及未完成附件。两个真实浏览器标签页复测：另一页选 PPT/Claude，原页仍发送 Sol Low、Skills off。切换模式也同步技能标签。 |
| P1 导航忽略未确认保存 | 打开历史会取消待保存计时器；新建、切换和继续发送没有统一等待已经在网络中的自动保存。 | 保存按快照排队；等待计时器和进行中的保存，失败时保留会话与草稿。浏览器注入保存 503 后，新建被拦截；恢复保存后可以继续。 |
| P1 旧版 PPT 数据可作为脚本执行 | JSON 解析失败后使用 `new Function` 执行模型输出。 | 删除执行回退；恶意表达式回归测试确认没有执行。 |
| P2 聊天图片在刷新后丢失 | 普通用户图片没有写入聊天序列化和服务端恢复消息；编辑只恢复第一张且依赖内存字段。 | 保存经过验证的图片引用；编辑恢复全部图片和原引用。合成图片发送后刷新并打开历史，图片仍加载成功。 |
| P2 App 更新版本不一致 | HTML 元信息和 `app-version.json` 不一致会持续误报更新。 | 保留并采用主分支 #90 的打包版本戳和更新循环防护，验证本轮产物版本一致。 |
| P2 登录弹层未隔离背景 | 屏幕阅读器和键盘仍可进入登录页后面的操作。 | 登录窗口声明模态语义，背景设为 inert，成功后恢复。浏览器未登录状态只暴露登录控件。 |
