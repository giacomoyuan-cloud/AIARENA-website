# AI 助手原生安卓功能对齐

目标：Kotlin + Jetpack Compose 直接调用现有 API，不以网页承载业务界面。此表为实施和验收清单，未通过的项目不得标为完成。

| 功能 | 原生实现与验收范围 | 状态 |
|---|---|---|
| 登录与退出 | 现有账号、Keystore 会话、进程重启保留、仅显式退出清除 | 安卓模拟器已验证重启/断网保留；退出流程复验中 |
| 管理 | 绑定经用户确认的管理员身份；普通账号不可见且 API 拒绝；开户后网页和 App 均可登录 | Oakley 已确认；服务端权限测试通过，原生交互验收中 |
| 对话 | 模型、思考深度、搜索、Markdown/代码/表格/公式、引用、停止/重试/编辑、流式回复、后台恢复 | 实施中 |
| 历史 | 同步、搜索、置顶、重命名、分组、移动项目、删除、模式识别 | 实施中 |
| 辩论 | 自由/角色/2v2、席位与总结深度、轮次、目标/详略/背景/约束、重试/跳过/修订/继续、导出 | 实施中 |
| 图片 | 官方模型、生成/编辑/多图、原图保存分享、蒙版、参数/质量/预览、继续编辑与版本记录 | 实施中 |
| 项目 | 独立范围、指令/记忆、资料与目录、项目对话、置顶/归档/删除/恢复 | 实施中 |
| 附件 | 系统选择器、照片/相机、文本/代码/PDF/Office、ZIP 展开、项目资料与 Skills 文件 | 实施中 |
| Skills | 自动/关闭/手选、偏好、模型约束、官方生成文件下载与删除 | 实施中 |
| 定时任务 | 创建/修改、作用域、时区与重复、暂停/恢复/立即运行、执行记录 | 实施中 |
| 账号与用量 | 显示名/头像/登录名/密码、用量和官方账单、主题、聊天提示词和记忆 | 实施中 |
| 兼容 | Android 8+、键盘/旋转/前后台、断网恢复、无 WebView 业务页面、原签名覆盖升级 | 实施中 |

网站已停用或未配置的供应商能力不伪装成可用。真实模型验收仅使用 GPT-6.1 Sol Low；其他验收使用隔离合成环境。
