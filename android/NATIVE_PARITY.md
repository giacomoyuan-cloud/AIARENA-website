# AI 助手原生安卓功能对齐

Kotlin + Jetpack Compose 直接调用现有 API。业务界面使用原生视图，无 WebView、无网页 HTML/JavaScript 业务包。全部模块已经实现；以下区分自动化合成验收、线上 API 验收与真实模型调用。
