# PDF 阅读与制作

使用官方 PDF Skill 读取或制作文件；内容提取同时关注版式与图表，不能用抽取文本代替视觉检查。生成文档后渲染页面，检查文字重叠、缺字、截断、表格、分页、页码、图像和引用。必要时修正并重新渲染。只交付真实生成并检查过的文件；扫描图像未完成识别要说明。
