# AI assistant: five whole-site design directions

This is an isolated design preview, using synthetic in-memory content. It makes no model, account, or production-data API calls. Production entry points and business behavior are unchanged.

Open `/design-review/`. The top five buttons switch the complete design system; the top-right page directory covers login, home, conversations, image generation/editing, debates, projects/materials, Skills, settings, Android installation, and the pitch tool. All designs adapt to mobile sizes.

Directions: Air (floating translucent surfaces), Paper (editorial whitespace), Studio (icon rail and persistent inspector), Graphite (low-glare dark creative space), Library (native three-column navigation).

Common interactive flows include sending local sample messages, model/effort selection, pin/delete/undo for synthetic chats, image ratio/size/style/search controls, reference attachments, project creation/editing and local file preview, debate seats/rounds, Skills toggles, settings, and login preview. Uploaded files remain in the page. Refresh resets synthetic state. The reference-tone control plays a brief local tone only after an explicit click; microphone access is never requested.

The illustrations are original static SVG preview assets, not results from a paid image-generation provider. Choosing a final design and integration into the actual app is a separate step.

Design reference: https://developer.apple.com/design/human-interface-guidelines/icons
